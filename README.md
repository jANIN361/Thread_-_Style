# Thread & Style

Thread & Style is an online clothing store management system.

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## How to Run the Project

1. Install XAMPP.
2. Start Apache and MySQL from the XAMPP Control Panel.
3. Copy the project folder into:
   C:\xampp\htdocs\
4. Open phpMyAdmin.
5. Create/import the project database.
6. Open the browser.
7. Go to:
   http://localhost/THREAD%20&%20STYLE/

## Main Features

- User registration and login
- Product browsing
- Product search
- Product details
- Shopping cart
- Order placement
- Feedback
- Admin login
- Product management
- Order management
- Feedback management

## API

DummyJSON was researched and tested as a possible product-data API.
However, API integration was not completed in the final version of the project.
The final website uses the existing product data.
